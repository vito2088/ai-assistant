## 简介

桌面小助手是一个本地优先的桌面应用，通过驻留桌面的方式把高频小操作聚合到一处：随手记一条待办、打开常用项目、启动常用软件、截一张图、录一段屏，都在同一个入口完成。可选配置 AI 服务，用于聊天、整理速记和解释截图。

- **本地优先**：记录保存在本机，无需账号，不联网同步。使用 AI 时，当前会话和选中的资料会发送给配置的模型服务；启用自动翻译后，截图识别出的文字也会自动发送。
- **桌面驻留**：可收起为可拖动的桌面小图标，需要时一键展开；支持固定置顶、开机启动。
- **跨平台**：基于 Tauri 2（Rust + TypeScript），目标是 Windows、macOS、Linux 三端。

## 功能

AI 栏目提供聊天、通讯录、私聊和群组，支持自定义模型、Codex CLI 与 Claude Code 联系人，点名分工、等待检查、多成员筛选和独立权限。CLI 联系人不需要配置本应用的 API 密钥。详见 [AI 通讯录与协作](docs/ai-collaboration.md)。设置里的功能树支持拖动调整栏目和工具顺序，详见 [功能显示与排序](docs/feature-visibility.md)。

工具提供统一的 **提醒** 入口，通过创建弹窗选择倒计时（支持暂停/继续）或指定日期时间，每项可开启屏幕提醒。到点后小横条从屏幕顶部滑入，停在顶部约 100px 处，可确认或延后五分钟；最小化时也能触发，错过的任务在应用恢复运行后补显示。详见 [定时器与提醒](docs/timers-reminders.md)。

| 栏目 | 功能 | 说明 |
| --- | --- | --- |
| 文档 | 待办 | 新增、完成/取消完成、确认删除；常驻输入框，Enter 即添加 |
| 文档 | 速记 | 多行文本的新增、编辑、删除，保存到本机 |
| 工作台 | 电脑档案 | 单行切换电脑，添加待绑定档案、改名、删除；本机与其他电脑的入口分别保存 |
| 工作台 | 项目 | 保存项目文件夹与首选编辑器，一次点击打开；支持搜索、编辑、删除 |
| 工作台 | 应用 | 添加常用程序路径，一次点击启动；支持搜索、编辑、删除 |
| 终端 | 本地与 SSH | 多会话 CMD / PowerShell / 系统 Shell；SSH 密码或私钥认证、主机指纹校验、SFTP 文件浏览与上传下载、逐项确认的 AI 命令和文件读取 |
| 工具 | 计算器 | 四则运算、括号、小数、百分比、正负切换、退格，最近 8 次计算历史 |

| 工具 | 待保存结果 | 截图与录屏的本机草稿：预览、另存、确认删除；取消保存或正常重启后仍可找回 |

工具首页仅显示功能入口和录屏状态；待保存截图只在截图页显示，待保存视频只在录屏页显示。

终端栏目使用二级侧栏管理连接和会话，文件与 AI 面板按需展开。设置可调整终端主题、字号和历史回滚行数。SSH 认证凭据由 Rust 后端处理并可保存到本机系统凭据库，不作为 AI 参数或聊天内容；AI 操作使用独立通道，执行前确认目标、目录和具体命令。当前受管终端支持主 AI 与 API 联系人，远程优先面向 Linux / POSIX 服务端；跳板机、MFA、Agent 与 CLI 联系人集成仍在后续计划中。详见 [终端使用与实现范围](docs/terminal.md)。

工具栏目提供「截图、录屏、计算器、提醒」四个小图标入口，可在设置中拖动调整顺序，点击进入，点击「‹ 工具」返回列表；正在录屏时返回列表不会停止录制，工具图标会显示红点。

截图工具栏提供「识别文字」和带 AI 标识的「翻译文字」按钮，结果显示在工具栏下方，可复制或点击 × 关闭；关闭后可再次点击工具栏按钮展开。设置中按顺序提供「截图后自动显示识别文字」与「截图后自动显示译文」开关，默认关闭，旧配置保持兼容。仅开启译文开关时只显示译文；仅开启识别开关时显示原文，面板内可主动点击「翻译」（复用已识别的文字）。两个开关都开启时显示原文与译文；都关闭时仍可从工具栏手动打开对应结果。关闭结果框后，本次截图不会自行弹回。

Windows 默认使用 Rust / Win32 / Direct2D 原生截图编辑器和录屏选区、倒计时、控制条。截图、录屏和文字结果框统一使用浅色面板、紫色选中态与同源矢量图标；录屏悬浮条提供紧凑的状态/计时与暂停/停止操作，原文和译文可分区复制。标注、复制、保存、贴图、离线 OCR 与 AI 翻译均已接入；全局快捷键由 Rust 注册并直接唤起原生窗口，主界面 JavaScript 忙碌时仍可截图。已移除旧 Windows WebView 捕获入口与预热窗口，不再提供试用/完整模式切换。详见 [原生截图迁移说明](docs/native-capture-v0.2.md)。

文字识别使用内置简体中文和英文 OCR，处理包含标注后的选区，无需 AI 模型、API 密钥或网络，不上传截图。AI 翻译将识别文字（不包含截图图片）发送给当前选中的模型，中文译成英文、英文译成中文；关闭窗口或改变选区会取消过期翻译。混合文本按中文字符与英文单词的数量判断主要语言。自动翻译需要启用 AI 功能并选中可用模型，纯文本模型即可。OCR 引擎和语言数据在 `npm run dev` / `npm run build` 前自动从依赖复制到本地资源目录。仅当 AI 功能已启用且已配置并选中模型时，Logo 旁显示 AI 标记；关闭 AI 不影响本地 OCR。

AI 联系人可创建待办、速记、提醒，读写授权目录、运行命令，以及在 Windows 调用截图、录屏和可选的桌面观察与控制。在联系人或会话权限中开启所需工具，实际执行状态与结果会保存在聊天中；自定义模型需支持工具调用。工具采用统一注册机制，便于后续扩展，详见 [AI 本机工具](docs/ai-tools.md) 与 [AI 通讯录与协作](docs/ai-collaboration.md)。

## 使用

### 窗口形态

- **关于**：在设置的关于栏目查看应用版本、开源许可和项目仓库；版本读取当前应用信息，主界面不再显示底部产品名及旧版本文字。
- **主界面**：默认 920 × 640 横向窗口，左侧导航、右侧内容，设置固定在左下方。功能入口可隐藏和排序，记住上次打开的栏目。小屏幕自动适配，详见[左右栏布局](docs/sidebar-layout.md)。
- **界面语言**：在「设置 → 界面语言」选择简体中文、English 或 Español，即时切换并记住选择。主界面、工具、AI 设置、截图操作和系统托盘支持翻译；用户记录、模型配置内容与 AI 回复保持原文。
- **桌面小图标**：可自由拖动；单击展开，悬停显示展开、新增待办、固定、紧凑列表按钮。
- **紧凑列表**：小窗口查看多条待办，可完成、删除、新增。
- **固定与置顶**：锁定窗口位置并显示在普通窗口上方。
- **最小化与托盘**：最小化保留任务栏图标；托盘菜单可显示窗口或退出（退出前自动完成录屏编码）。
- **功能显示**：在「设置 → 功能显示」按树形勾选栏目和子功能，立即生效并在重启后保留；隐藏不会删除任何数据。

### 工具用法

- **计算器**：点击按键或直接键入算式，Enter 或 `=` 计算，Esc 或 `C` 清空。例：`(2+3)*4` → `20`，`200*10%` → `20`。
- **截图**：选择显示器后开始截图，在桌面拖动框选（可全屏或复用上次选区），用工具栏标注；Ctrl+Z / Ctrl+Shift+Z 撤销重做，对钩 / Enter / Ctrl+C 复制并结束截图，X 前的保存按钮或 Ctrl+S 另存 PNG，Esc 取消。工具栏的「固定」可把标注结果变成桌面置顶贴图，支持多张并存，悬停操作条位于图片下方，不遮挡小图。
- **录屏**：选择显示器并框选区域，开始录制后可用控制条暂停/继续/结束，结束后预览并另存。Windows 使用原生捕获与 H.264 编码，帧率可设 15/30/60；H.264 下选区宽高自动对齐为偶数像素。
- **默认目录**：在「设置 → 截图与录屏」分别设置截图、录屏目录，作为保存对话框的初始位置。

- **全局快捷键**：默认 Ctrl+Alt+A 截图、Ctrl+Alt+R 开始或停止录屏；可在设置中改键或停用。组合键被占用时会提示，应用需保持运行。

当前录屏无声音；滚动长截图、窗口自动识别、音频录制与视频剪辑尚未实现。本地文字识别支持离线 OCR；AI 图片文字提取需要支持图片的模型。

### AI 用法

1. 在「设置 → AI 模型」点击「添加模型」，选择国内、国外或本机服务预设，也可完全自定义。填写配置名称，在底部「模型映射」中选择实际模型，并按服务要求填写 API 密钥，然后点击「保存并测试」。云端地址使用 HTTPS，本机服务支持 localhost / 127.0.0.1 的 HTTP。
2. 如模型支持图片，勾选图片能力；设置默认翻译语言。该选项不会让纯文本模型获得图片能力。
3. 在 AI 通讯录中添加联系人并绑定模型服务，选择角色、工作目录和权限，再私聊或加入群组。支持 `@DS 先实现，@GPT 等 DS 完成后检查`；可筛选只看一位或多位成员。Codex / Claude Code 可直接使用本机 CLI 的模型和登录配置。AI 翻译、速记和截图助手使用「设置 → AI 模型」顶部选择的「主 AI」，切换后自动保存；聊天联系人保持各自绑定。详情见 [AI 通讯录与协作](docs/ai-collaboration.md)。
4. 速记下方可整理、摘要和提取待办；结果在当前条目内显示。替换原文后可以撤销；原文被其他操作修改时会阻止覆盖。待办先展示可编辑候选，只有点击「添加勾选项」才写入。
5. 展开截图详情后可解释、翻译、提取文字，点击「继续聊」会携带原图片和已有回答进入 AI 栏目。录屏暂不支持 AI 分析。

设置页只显示已保存的模型列表；点击「添加模型」或「编辑」打开配置弹窗。弹窗表单可滚动，标题和保存按钮固定显示；顶部「测试连通」直接测试当前草稿并显示耗时，不保存配置；底部为「取消 / 保存配置」，保存成功关闭弹窗，关闭未保存的修改会询问是否放弃。模型配置表单底部提供「模型映射」：每条包含显示名称与实际模型 ID，选中一条并保存后生效。旧配置显示为一条映射，无需迁移密钥。「添加映射」支持手填，「一键设置」补入服务预设且保留已有项；「获取模型列表」通过当前地址的兼容 `/models` 接口查询，获取后点击实际模型输入框右侧的下拉箭头，弹层内可搜索并点击模型，直接替换当前行（保留自定义显示名称）；按 Esc 或点击外部可关闭。每个配置最多 50 条映射。获取列表无需先保存，不会自动切换模型；认证失败或接口不支持时可继续手动配置。图片能力按服务说明设置。默认翻译语言通过下拉框选择中文、英语、西班牙语等常用语言，旧配置中的其他语言值仍保留。智谱分为「标准 API」和「Coding Plan」两个预设，按账号通道选择，不能直接填写 CC Switch 的 Anthropic 地址。详见 [连接测试与智谱接入](docs/ai-connection.md)。

AI 仅通过手动引用或已授权工具读取资料；开启文件、命令或桌面权限后，模型可按任务主动调用对应工具。当前接入的模型服务会接收聊天上下文、授权工具结果，以及开启桌面观察并调用时的截图。聊天和附件快照保存在本机，API 密钥单独保存在系统凭据库。未配置 AI 时，其他功能照常使用。可在设置中清空聊天与附件，已另存的速记和待办会保留。

## 数据存储

所有数据保存在本机：

- 待办、速记、电脑档案、项目/应用入口和窗口位置存于系统应用数据目录的 SQLite 数据库；用户设置存于同目录的 `settings.json`。
- AI 聊天与引用资料的快照也保存在 SQLite；清理截图草稿或修改原速记不影响已有聊天上下文。密钥不写入普通设置表。
- Windows 截图在内存中框选和标注，对钩直接复制，不生成底图草稿；原生另存直接写入所选文件。贴图、录屏及其他系统截图的未保存结果保留在应用数据目录的 `capture-drafts`，可预览、另存或删除。OCR 中间图仅按需生成，识别结束或取消后清理。
- 删除项目或应用入口只移除记录，不会删除磁盘文件。
- 强制终止进程时，尚未完成编码的视频可能无法播放。

## 开发

技术栈：Tauri 2 · Rust · TypeScript · Vite · SQLite。

需要 Node.js、Rust 和各系统的 [Tauri 开发依赖](https://v2.tauri.app/start/prerequisites/)。

```powershell
npm install     # 安装依赖
npm run tauri dev   # 本地开发运行
npm run tauri build # 构建安装包
```

开发检查：

```powershell
npm test
npm run build
cd src-tauri
cargo check
cargo test --lib
```

## 更多文档

### JSON 设置文件

设置采用二级侧栏，按常规、功能显示、截图、录屏、快捷键、AI 模型、高级和关于分类，右侧仅显示当前分类内容。「高级设置」提供「编辑 JSON」「外部编辑器打开」「打开文件夹」「重新加载」和「恢复默认」。用户设置保存在应用数据目录的 `settings.json`，Windows 默认位置为 `%APPDATA%\com.myassistant.desktop\settings.json`；同目录的 `settings.default.json` 是默认配置参考。已有设置会从 SQLite 自动迁移，待办、速记、聊天记录及窗口位置仍保存在数据库，模型密钥仍由系统凭据库管理。

内置编辑器在保存前检查 JSON 语法、字段类型、取值范围、快捷键和模型引用，错误会显示行列或字段路径，不会覆盖原文件。外部修改不合法时，应用使用内置默认配置，在设置页显示错误并保留原文件；修正后重新打开设置页或点击「重新加载」即可恢复。正在进行的捕获或 AI 任务会继续运行，相关配置可在任务结束后重新加载。

配置使用标准 JSON（不支持注释和尾随逗号）。文件中保持完整字段，可在内置编辑器中查看默认配置；`autostart: null` 表示保留当前系统开机启动状态。保存采用临时文件替换，内置编辑器也会拒绝覆盖打开后被其他操作修改的文件。
