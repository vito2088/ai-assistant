# 应用图标

唯一源文件为 `app-icon.svg`：紫色渐变圆角底与白色四角星，和主界面品牌图标一致。底色区域完全不透明，四周圆角以外透明，不使用原先中心半透明圆形，避免桌面背景透入后像气泡。

在仓库根目录运行 `npm run icons`，通过 Tauri CLI 同步生成 ICO、ICNS、桌面 PNG 及移动端图标。不要手动修改生成图或使用旧的 `source.png`，旧源图已经移除。

Windows ICO 包含 16、24、32、48、64、256 像素版本，覆盖常见桌面尺寸和显示缩放。修改后需重新编译应用、打包安装器，才能更新 EXE 和新建快捷方式中的图标。仅重新运行 bundle 命令不会替换旧 EXE 内嵌图标。

Windows 桌面快捷方式左下角的小箭头由系统添加，保留默认行为。旧快捷方式可能暂时显示系统缓存，验收应检查新构建 EXE 中的图标及新建快捷方式。
