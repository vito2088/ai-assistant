# 桌面小助手

一个可驻留桌面的本地小助手，包含文档、工作台、工具和设置。技术栈：Tauri 2、Rust、TypeScript、SQLite，目标平台为 Windows、macOS、Linux。

## 功能清单

| 栏目 | 功能 | 当前支持 |
| --- | --- | --- |
| 文档 | 待办 | 新增、完成/取消完成、确认删除；常驻输入框支持 Enter 添加 |
| 文档 | 速记 | 新增、编辑、删除；多行文本，保存到本机 |
| 工作台 | 电脑档案 | 单行切换电脑，添加待绑定档案、改名、删除；本机与其他电脑的入口分别保存 |
| 工作台 | 项目 | 选择项目文件夹和编辑器，保存后一次点击打开；支持搜索、编辑、删除入口 |
| 工作台 | 应用 | 添加常用程序路径，一次点击启动；支持搜索、编辑、删除入口 |
| 工具 | 计算器 | 图标入口；四则运算、括号、小数、百分比、正负切换、退格、最近 8 次计算历史 |
| 工具 | 截图 | 桌面框选/全屏/上次选区；移动与八方向缩放选区；画笔、箭头、矩形、椭圆、文字、马赛克、序号；颜色与粗细、撤销/重做、复制、完成后保存 PNG |
| 工具 | 录屏 | Windows 区域/全屏录制；倒计时、暂停/继续、可拖动悬浮控制条、选区边框、计时；结束后预览并另存无声 MP4 |
| 工具 | 待保存结果 | 截图与录屏本机草稿、预览、另存、确认删除；取消保存或正常重启后仍可找回 |
| 设置 | 开机启动 | 读取并修改系统的开机启动状态 |
| 设置 | 固定与置顶 | 锁定窗口拖动，并显示在普通窗口上方；按钮显示选中状态 |
| 设置 | 截图与录屏 | 独立默认保存目录、0/3/5/10 秒倒计时、15/30/60 FPS、Windows 录屏鼠标指针 |

工具栏目使用“计算器、截图、录屏”三个小图标，不使用子标签栏。点击图标进入工具，点击“‹ 工具”返回图标列表。录屏中返回列表或切换主栏目不会停止录制，工具标签会显示红点。

截图工具栏的 **固定** 可将当前选区连同标注变成桌面置顶贴图：拖动图片可移动，悬停显示“已置顶 / 另存 / ×”，可解除或恢复置顶，按 Esc 或 × 关闭。支持同时固定多张图片；关闭贴图后截图仍留在待保存列表，退出应用后不自动重新打开贴图窗口。

### 桌面显示与窗口

- **主界面**：文档、工作台、工具、设置四个大栏目。
- **桌面小图标**：可直接拖动；单击展开，悬停显示展开、新增待办、固定、紧凑列表按钮。
- **紧凑列表**：在小窗口查看多条待办，可完成、直接删除；底部“新增”打开小弹窗，保存后留在紧凑列表并立即更新。Enter 添加，Esc 关闭弹窗并保留草稿。
- **最小化**：保留任务栏图标，点击即可恢复；系统托盘菜单也可显示窗口。
- **托盘恢复**：左键单击/双击托盘图标，或右键选择“显示小助手”，恢复并展开窗口；窗口位置不在当前屏幕时自动移回屏幕内。最小化产生的异常坐标不会保存。“结束录屏并预览”仅在录制期间显示。
- **退出**：右上角“×”或托盘菜单退出应用。正在录屏时先完成编码，结果保留在本机待保存列表。
- 自动记住窗口位置、显示方式、固定状态和上次打开的大栏目。展开与紧凑列表使用一致的圆角和单层边框，无外沿阴影。

### 工具怎么用

**计算器**：点“工具 → 计算器”，点击数字键或在输入框中键入算式，Enter 或“=”计算，Esc 或“C”清空。例：`(2+3)*4` 得到 `20`，`200*10%` 得到 `20`；百分比按当前数字除以 100 计算。历史记录仅保留在当前运行期间。

**截图**：点“工具 → 截图”，选择显示器，点击“开始截图”。默认先最小化小助手，然后在桌面拖动框选；选区可移动、调整大小，也可选择全屏或复用上次选区。在悬浮工具栏选择画笔、箭头、形状、文字、马赛克或序号。文字输入后按 Ctrl+Enter 确认；Ctrl+Z 撤销、Ctrl+Shift+Z 重做、Ctrl+C 复制图片，Enter 完成，Esc 取消。完成后才弹出 PNG 保存对话框；取消保存会保留结果。

**录屏**：点“工具 → 录屏”，选择显示器并框选区域，点击“开始录制”进入倒计时（Esc 返回选区）。开始后显示可拖动的控制条和录制区域边框；可以暂停、继续或结束，暂停时间不计入视频时间线。控制条与选区边框在 Windows 上排除于捕获画面。也可从主面板或系统托盘结束。结束后恢复小助手，预览视频并点击“另存”选择位置。Windows 使用原生捕获与 H.264 编码，帧率可设 15/30/60，实际帧数受画面更新和设备性能影响；H.264 选区宽高向下对齐为偶数像素。

**默认目录**：在“设置 → 截图与录屏”分别选择截图、录屏目录。该目录作为完成后保存对话框的初始位置，仍可修改文件名或另选目录。

当前仍为无声录屏；滚动长截图、窗口自动识别、OCR、全局热键、录制音频与视频剪辑尚未实现，详见 [工具增强设计 v0.2](docs/tools-module-v0.2.md)。首次使用时可能需要操作系统授予屏幕捕获权限。

## 运行

需要 Node.js、Rust 和各系统的 [Tauri 开发依赖](https://v2.tauri.app/start/prerequisites/)。

```powershell
npm install
npm run tauri dev
```

构建安装包：

```powershell
npm run tauri build
```

开发检查：

```powershell
npm run build
npm test
cd src-tauri
cargo check
cargo test --lib
```

## 数据与平台支持

待办、速记、电脑档案、项目/应用入口和设置保存在系统应用数据目录的 SQLite 数据库中。截图与录屏先写入本机应用数据目录的 `capture-drafts`，正常结束后可预览、另存；保存成功才清理对应草稿。未保存草稿需要自行另存或删除，不自动清理；强制终止进程时尚未完成编码的视频可能无法播放。删除项目或应用入口只移除记录，不会删除磁盘文件。

| 平台 | 截图与录屏 | 验证情况 |
| --- | --- | --- |
| Windows | 原生 Windows Graphics Capture；PNG 截图、H.264/MP4 无声录屏，无需额外安装 FFmpeg | 已在本机验证；需系统支持 Windows Graphics Capture（Windows 10 1903 及以上） |
| macOS / Linux | 使用系统 WebView 的屏幕选择接口，支持时可截图或通过 MediaRecorder 录制；格式按可用编码器选择 WebM/MP4 | 已提供能力检测和权限/取消提示；尚未在对应系统实测，缺少接口时会提示不支持 |

macOS 可能需要在“系统设置 → 隐私与安全性 → 屏幕录制”中允许本应用；Linux 的屏幕捕获取决于桌面环境、屏幕共享门户和 WebKitGTK 能力。Windows 支持区域录屏；其他系统使用系统选择器提供的来源，尚未提供区域裁剪与桌面录制控制条。截图标注、保存草稿的前端逻辑共用，但 macOS/Linux 尚未实机验证。

项目和应用入口目前通过手动选择本地路径添加。其他电脑可先建立待绑定档案；账号同步与跨电脑绑定尚未实现。各系统的已安装应用自动发现、Linux Wayland 下的置顶和位置恢复，以及 macOS/Linux 打包后的启动入口仍需在对应系统上验证和完善。
