# 主界面左右栏布局

更新日期：2026-10-30。

主界面改为横向长方形，默认 **880 × 620 逻辑像素**。左侧是功能导航，右侧是内容区；设置固定在导航底部。这里的“长比宽多”指横向长度大于高度。原默认尺寸 800 × 560 自动更新为新默认值，手动调整过的其他尺寸继续保留。

## 导航与显示

- 左侧功能入口采用 SVG 图标和文字，选中项使用淡紫背景及侧边标记。
- 导航继续读取设置中的功能显示和拖动顺序。隐藏所有功能后仍保留设置入口。
- 左侧导航和右侧内容分别滚动，右侧页面滚动时不影响导航及窗口操作按钮。
- 工具栏目的录屏状态红点继续显示在左侧“工具”入口。
- 设置采用二级侧栏，选择分类后右侧只显示对应内容。

## 窗口与小屏幕

每次启动在恢复模式尺寸后，将窗口居中到当前显示器的工作区，不再使用上次拖动的位置。运行期间仍可自由拖动，最小化后恢复保留当前位置。展开时根据当前显示器工作区和缩放比例限制窗口大小，为任务栏及屏幕边缘预留空间。窄屏幕下主导航改为图标上、文字下，设置二级侧栏同步收窄，右侧内容独立滚动。桌面小图标模式仍为 184 × 184，紧凑列表仍为 360 × 360。

展开窗口支持四边与四角拖动缩放，使用系统原生缩放操作。常规最小尺寸为 520 × 420，较小显示器按可用空间适配。用户调整后的展开尺寸保存在本机 WebView 的 `expanded_window_size` 偏好中，收起、紧凑列表和再次展开不会覆盖该尺寸；再次启动仍居中。

## 恢复默认设置

“设置 → 高级设置”提供“恢复默认”按钮，确认后恢复窗口默认尺寸并居中，重置语言、功能显示与顺序、置顶、开机启动、截图录屏快捷键和捕获偏好，并返回常规设置。AI 模型配置及凭据、待办、速记、项目、应用、提醒、历史记录与文件保留。设置文件通过原有校验和并发修改检查保存；文件有 JSON 语法错误时需先修复后再重置。捕获等任务繁忙时，沿用设置重新加载的延后生效提示。

## 应用内确认

删除待办、速记、电脑档案、项目/应用入口、AI 联系人/会话/模型、截图录屏草稿，以及清空历史、恢复默认、未保存修改、CLI 安装和 AI 权限提升，统一使用 `src/app-dialog.ts` 的应用内确认组件。样式延续浅色面板、圆角边框和紫色主色，无阴影；删除操作使用红色确认按钮，默认聚焦取消。

组件返回异步决定，只有明确确认后才执行操作。取消、关闭与 Esc 均返回取消；Tab 在弹窗按钮中循环，键盘事件不穿透到后面的编辑器或工具。重复请求不重复执行，相邻不同请求按顺序显示。确认框挂载到页面渲染容器外，后台刷新或重建原编辑器时保持在最上层；取消后回到原来的编辑界面。

验证包括实际待办删除处理函数的确认前等待/取消不删除，以及浏览器中联系人编辑器内的删除、重复点击、Esc、焦点恢复、未保存 JSON 的保留/放弃、后台重绘和三种语言的小窗口长文本布局。文件与目录选择继续使用系统选择器。

## 设置二级导航

点击主导航“设置”，中间显示设置分类，右侧显示当前分类的内容：

- 常规设置：界面语言、开机启动和固定置顶。
- 功能显示：功能树的显示开关和拖动排序。
- 截图设置：默认目录、自动识别文字和自动翻译。
- 录屏设置：默认目录、倒计时、帧率和鼠标指针。
- 快捷键：截图与录屏的全局快捷键。
- AI 模型：模型配置与当前模型选择。
- 高级设置：JSON 设置文件入口和恢复默认设置。
- 关于：版本、开源许可和 GitHub 仓库链接。

分类与内容分别滚动，各分类记住自己的滚动位置；`settings_section` 本地偏好记住最近选中的分类。上下方向键、Home 和 End 可切换分类。工具页的截图/录屏设置按钮以及 AI 页的配置入口会直接选中对应分类。所有功能被隐藏时，设置及全部设置分类仍可访问。

外部 JSON 无效时，各分类显示错误与修复入口，设置分类和 JSON 修复按钮保持可用；配置变更延后生效的提示也会在各分类中展示。

## 项目与应用表单

“添加项目”“添加应用”及已有入口的“编辑”统一使用居中弹窗，背景列表不被表单撑开。保留名称、应用入口或项目文件夹，以及项目的编辑器程序选择。支持关闭、取消和 Esc；保存时禁用重复提交及取消操作，失败在弹窗内显示原因并保留输入，成功后关闭弹窗并刷新列表。

弹窗独立于主内容的重新渲染，后台数据更新不会重建输入框或丢失焦点。路径浏览仍使用系统选择器，取消选择不清空已有路径；弹窗适配较窄窗口并支持内部滚动。

顶部保留拖动区、固定、收起、最小化和退出按钮；主界面底部没有产品名和版本栏，版本在设置的“关于”查看。
