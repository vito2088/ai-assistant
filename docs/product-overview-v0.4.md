# 桌面小助手｜产品总览 v0.4

- 状态：讨论稿，尚未开发
- 日期：2026-10-23

## 1. 产品定位

桌面小助手是一个可持续增加功能的本地应用。用户可以将常用入口留在桌面，需要时快速展开操作。待办、项目管理和软件管理都通过统一入口访问。

当前规划：

| 功能 | 用途 | 详细设计 |
| --- | --- | --- |
| 桌面待办 | 快速新增、查看和完成任务；支持小图标、逐条显示及固定置顶 | [桌面待办 v0.2](desktop-todo-v0.2.md) |
| 项目管理 | 保存项目文件夹与首选编辑器，点击即可打开 | [项目管理 v0.1](project-manager-v0.1.md) |
| 软件管理 | 保存常用软件入口，点击即可启动 | [软件管理 v0.1](software-manager-v0.1.md) |

## 2. 应用层级

```text
桌面小图标 / 主窗口入口
          │
          ▼
       小助手主界面
       ├─ 待办
       ├─ 项目
       └─ 软件
```

- 小图标是小助手的统一桌面入口，不只代表待办。
- 展开后主界面提供“待办”“项目”“软件”三个入口或标签，记住上次访问的功能。
- 待办的逐条显示属于待办功能的专属显示方式。项目管理和软件管理首版在主界面中使用。
- 小图标悬停时，保留“展开、新增待办、固定、逐条待办”等快捷操作；项目和软件通过展开主界面进入。后续可将常用软件加入快捷菜单，但首版先控制菜单密度。
- “固定”是小助手窗口层面的行为：锁定位置并在普通应用窗口上方显示；切换到项目或软件页时同样有效。
- “最小化”隐藏小助手的桌面窗口，但应用继续运行，可从系统入口恢复。

## 3. 主界面草图

```text
┌──────────────────────────────────────┐
│ 小助手                  📌   −   ○  │
├──────────────────────────────────────┤
│ [待办]   [项目]   [软件]              │
├──────────────────────────────────────┤
│                                      │
│  当前功能的内容区域                  │
│                                      │
└──────────────────────────────────────┘
```

主界面可拖动、收起为小图标，固定与最小化遵循统一规则。待办旧设计稿中的“展开列表”在本版产品结构里对应“主界面打开待办页”；详细待办交互仍以其设计稿为准。

## 4. 跨功能规则

- 待办、项目和软件入口数据分别存储，但都在本机持久保存。
- 主界面切换功能时，不清空未完成的数据操作；若编辑表单已有未保存内容，应提示保存或放弃。
- 项目快捷打开属于本地应用启动操作；启动失败时在小助手中给出错误原因和修复入口。
- 软件快捷启动也需要明确的点击动作；启动失败时提示原因和编辑入口。
- 首版不要求登录、云同步或跨设备共享。
