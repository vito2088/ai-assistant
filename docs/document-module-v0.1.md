# 文档模块｜设计 v0.1

- 日期：2026-10-23
- 状态：当前实现方案
- 对应产品总览：[v0.7](product-overview-v0.7.md)

## 1. 导航结构

```text
小助手主界面
├─ 文档
│  ├─ 待办
│  └─ 速记
├─ 项目
├─ 软件
└─ 设置
```

“文档”替代原来的顶层“待办”。进入文档后，可在“待办”和“速记”子栏目之间切换；上次打开的子栏目会在重启后恢复。旧版本保存的顶层 `todo` 页面自动迁移到“文档 → 待办”，不改动已有待办数据。桌面小图标中的“新增待办”仍直接打开“文档 → 待办”的输入框。

## 2. 待办子栏目

沿用[待办设计 v0.4](desktop-todo-v0.4.md)：输入框常驻，点一次“添加”或按 Enter 保存；待办列表支持完成、删除和紧凑列表。待办数据与速记分开存储，切换子栏目不会改变待办状态。

## 3. 速记子栏目

速记用于保存临时想法、线索和不需要完成状态的短文本。

- 页面顶部常驻多行输入框；输入内容后点击“保存速记”创建一条记录。
- 内容限 1～2000 个字符；空白内容不能保存。保存失败时保留输入并显示错误。
- 新保存或更新的记录排在最前面。列表展示文本摘要和最近修改时间，长内容可通过“编辑”进入输入框查看与修改。
- 点击“编辑”将该条内容带入输入框；保存修改后更新原记录，不生成副本。可取消编辑。
- 点击“删除”前确认；删除只作用于对应速记，不影响待办。
- 数据保存在与待办相同的本机 SQLite 数据库中的独立 `notes` 表，不需要登录。

## 4. 验收标准

| 场景 | 预期 |
| --- | --- |
| 旧版本最后停留在顶层待办页 | 更新后打开“文档 → 待办”，历史待办仍在 |
| 切换“待办 / 速记” | 两个子栏目各自显示数据，切换后草稿仍保留 |
| 新增速记 | 保存后立即出现在速记列表顶部，重启后仍在 |
| 编辑速记 | 原记录内容和修改时间更新，不新增重复记录 |
| 删除速记 | 确认后只删除所选速记 |
| 从桌面小图标新增待办 | 打开“文档 → 待办”并聚焦输入框 |

## 5. 后续迭代

速记暂不包含富文本、图片、附件、标签、搜索或云同步。待实际使用后再决定是否增加这些能力。
