# 小助手 v0.2.0

发布日期：2026-10-29。

## 下载与安装

在本页 **Assets** 中选择安装包；`Source code` 是源码。

| 系统 | 安装包 |
| --- | --- |
| Windows x64 | `my-assistant_0.2.0_windows_x64-setup.exe`（推荐）或 `.msi` |
| macOS Apple Silicon | `my-assistant_0.2.0_macos_aarch64.dmg` |
| macOS Intel | `my-assistant_0.2.0_macos_x64.dmg` |
| Linux x64 | `my-assistant_0.2.0_linux_x86_64.AppImage` 或 `.deb` |

附件提供 `SHA256SUMS.txt` 校验清单。安装包仅在 [GitHub Releases](https://github.com/vito2088/ai-assistant/releases/latest) 提供，Gitee 仓库仅同步源码。

## 本版更新

- **Windows 原生捕获**：截图、录屏选区、倒计时和悬浮控制条切换为 Rust / Win32 / Direct2D，移除旧 Windows 全屏捕获 WebView 和试用模式。全局快捷键由 Rust 直接注册和处理。
- **完整截图功能**：保留框选/全屏/上次选区、画笔、箭头、形状、中文文字、马赛克、序号、颜色与粗细、撤销/重做；对钩复制，独立另存按钮，支持桌面贴图。
- **文字识别与翻译**：内置离线简中/英文 OCR，可自动识别或自动显示译文；原文/译文分区显示并单独复制。AI 翻译仅发送识别文字，需要配置模型。
- **录屏界面**：紧凑状态计时条，支持拖动、暂停、继续、停止与预览；统一浅色面板、紫色选中态、圆角与同源矢量图标。
- **提醒**：定时器与提醒统一入口，弹窗创建、编辑、暂停/继续；支持屏幕顶部横条提醒及到期任务恢复。
- **AI 与设置**：未配置可用密钥时显示配置引导；功能树支持拖动排序与显示开关，配置按本机保存。
- **工具整理**：工具首页不再汇总数据列表，截图与视频只在各自功能页显示；开始按钮旁新增设置齿轮，一次点击跳转到对应设置卡片。
- 保留待办、速记、电脑档案、项目与编辑器入口、应用启动、开机启动及桌面置顶功能。

## 平台与验证

Windows 原生截图、保存、贴图、离线 OCR、区域录屏、暂停/继续、快捷键及 MP4 解码已在本机验证。macOS/Linux 保留系统选择器和浏览器捕获适配，原生选区与控制条尚未移植，安装和系统权限仍需对应系统实测。录屏暂不包含声音。

本地验证：49 项前端测试、36 项 Rust 测试，前端构建和版本一致性检查。Windows 安装包尚未配置代码签名；macOS 使用 ad-hoc 签名，尚无 Developer ID 公证。
