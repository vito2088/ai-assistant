# 桌面待办小助手｜产品设计 v0.3

- 状态：产品设计稿；首版已开发，具体进度见[开发状态](implementation-status-v0.1.md)
- 日期：2026-10-23
- 上一版：[v0.2](desktop-todo-v0.2.md)
- 本版调整：统一窗口圆角与单层外观、明确顶部操作图标、新增待办置顶并显示保存反馈

## 1. 产品目标

用户可以把待办放在桌面随时查看。需要专注工作时，助手缩成一个小图标；鼠标移到图标上即可快速新增、展开或固定。用户也可以只看一条待办，减少占用空间。固定后，助手停留在选定位置并保持在普通软件窗口上方。

目标平台为 Windows、macOS、Linux 桌面系统；平台窗口限制见[跨平台技术方案](technical-choice-v0.3.md)。

## 2. 三种显示状态

| 状态 | 桌面上看到什么 | 主要操作 |
| --- | --- | --- |
| 展开 | 待办列表和标题栏 | 新增、完成、删除、切换逐条显示、收起、最小化、固定 |
| 小图标 | 一个可拖动的小图标；悬停时周围出现按钮 | 展开、新增、固定、逐条显示、最小化 |
| 逐条显示 | 小卡片，每次只显示一条待办 | 上一条、下一条、完成、回到列表、收起、固定 |

**最小化**是单独的窗口操作：从桌面隐藏助手，但应用继续运行并保留任务栏或系统托盘入口；点击入口恢复到最小化前的显示状态。它与“收起为桌面小图标”不同。具体采用任务栏还是托盘入口，待开发前确定。

状态切换：

```text
展开列表 ──收起──→ 桌面小图标 ──展开──→ 展开列表
    │                    │
    └──逐条显示──→ 单条卡片 ←──逐条显示──┘
                         │
                         └──回到列表──→ 展开列表

任一桌面显示状态 ──最小化──→ 后台入口 ──恢复──→ 原状态
```

切换状态时保留各状态的位置。首次切换到新状态时，新窗口以原位置为参考，自动调整到屏幕可见区域内。

## 3. 界面草图

### 展开列表

```text
┌────────────────────────────────┐
│ 待办              📌  ▣  −  ○ │  ← 固定 / 逐条显示 / 最小化 / 收起
├────────────────────────────────┤
│ ○  回复邮件                    │
│ ○  整理周计划                  │
│ ●  已完成的事项                │
│                         ＋     │
└────────────────────────────────┘
```

### 桌面小图标

```text
          [展开]
 [逐条]    ◉    [新增]
          [固定]
```

功能按钮围绕小图标出现；实际布局要避免按钮被屏幕边缘裁切。最小化可放在小图标的右键菜单中，避免悬停按钮过多。固定状态用图钉外观清楚区分。

### 逐条显示

```text
┌──────────────────────────┐
│ 📌   待办  2/5      ○   │
├──────────────────────────┤
│ ○  整理周计划            │
├──────────────────────────┤
│ 〈 上一条      下一条 〉  │
│ 列表  ＋  收起  最小化   │
└──────────────────────────┘
```

草图只表达结构。展开和逐条显示窗口采用同一圆角半径和单层面板外观；顶部三个操作按钮分别表示“固定并置顶”“收起为桌面小图标”“隐藏到系统托盘”。托盘按钮使用常见的最小化横线图标，悬停提示明确说明会隐藏到系统托盘。

## 4. 详细交互

### 4.1 收起为小图标

- 展开列表点击“收起”后，列表变为桌面小图标；待办内容仍保留。
- 小图标常态只显示主体，鼠标移入后出现周围的功能按钮；鼠标移出后短暂延时隐藏，避免指针移向按钮时按钮闪烁消失。
- 点击图标主体直接展开列表；周围按钮可分别执行展开、新增、固定和逐条显示。
- 点击“新增”时展开主界面的待办输入框，输入后按 Enter 保存；Esc 取消输入。
- 小图标可通过图标主体拖动；固定后不允许拖动。
- 悬停按钮应可用键盘聚焦；右键菜单提供相同功能，方便触控板与键盘用户操作。

### 4.2 新增、完成与删除

- 在展开列表和逐条显示状态点击“＋”后，输入框自动获得焦点。
- 输入非空内容后按 Enter 或点击“添加”保存；纯空格不能保存。单条内容暂限 200 个字符。
- 保存成功后收起输入框，在未完成列表**顶部**显示新事项，并给出“已加入待办列表”提示。从小图标或逐条显示状态新增时，先展开待办主界面，保存后停留在主界面。
- 点击事项前的状态按钮，在未完成和已完成之间切换。
- 展开列表中未完成事项在上、已完成事项在下；删除单条事项后提供短时间撤销入口。
- 列表为空时显示“暂无待办，点击＋添加”。

### 4.3 逐条显示待办

- 一次只显示一条待办；优先展示未完成事项，按创建顺序排列。
- “上一条 / 下一条”在当前可展示事项间切换，显示当前位置，例如 `2/5`；到边界时禁用对应按钮，不循环跳转。
- 完成当前事项后，自动切换到下一条未完成事项；若没有未完成事项，显示“都完成了”，可返回列表查看已完成事项。
- 没有任何事项时，显示空状态和“＋”入口。
- 长文本可在卡片内换行，卡片设最大高度，超出部分可滚动或展开查看，不能遮住操作按钮。
- “逐条显示”只是展示方式，不创建新的待办副本；在任一状态修改内容，其余状态立即同步。

### 4.4 拖动、固定与层级

- 展开列表从标题栏空白区域拖动；小图标从主体拖动；逐条卡片从顶部空白区域拖动。按钮、输入框和待办内容的点击不触发拖动。
- **固定**同时表示两件事：锁定当前位置，且保持在普通应用窗口之上（始终置顶）。固定后仍可点击、展开、收起、新增及切换显示方式。
- 未固定时允许拖动，窗口按系统正常层级显示，可能被其他软件遮挡。
- 固定状态在三种显示状态间同步，重启应用后保留。
- 固定时若切换显示状态，窗口以当前锚点调整尺寸并保持可见；用户可先解除固定，再调整位置。
- 靠近屏幕边缘时至少保留可操作区域；悬停按钮自动向屏幕内侧展开。分辨率或显示器布局变化时，将助手移回可见区域。
- 始终置顶的范围暂定为普通桌面应用；系统级界面（如锁屏、安全提示、全屏独占应用）按操作系统规则处理。

### 4.5 最小化、退出与恢复

- “最小化”从桌面隐藏助手，应用继续运行；通过任务栏或托盘入口恢复。
- “退出应用”与最小化明确区分，放在右键菜单或入口菜单中。
- 重新启动应用时恢复上次的显示状态、位置、固定状态和待办数据；如果上次是最小化状态，启动后默认恢复到最小化前的桌面状态，避免启动后找不到助手。
- 首次启动时展示展开列表，位于主屏幕右侧可见区域。

## 5. 首版范围与验收标准

| 功能 | 验收标准 |
| --- | --- |
| 展开与收起 | 列表可缩为桌面小图标，点击图标主体可恢复列表；切换后待办不丢失。 |
| 悬停菜单 | 鼠标移入小图标出现展开、新增、固定、逐条显示入口；移向按钮时菜单不意外消失；屏幕边缘不裁切。 |
| 最小化 | 桌面上的助手隐藏，可从系统入口恢复到原显示状态；退出命令可单独使用。 |
| 新增 | 各状态均有新增入口；空内容不能保存；保存后新事项显示在列表顶部并有明确反馈。 |
| 逐条显示 | 每次仅显示一条未完成事项，可前后切换并完成；没有未完成事项时有明确空状态。 |
| 固定 | 固定后不能拖动，普通应用窗口不会遮挡它；解除固定后可拖动并恢复普通窗口层级。 |
| 持久化 | 重启后待办、完成状态、各状态位置、固定状态和上次显示状态正确恢复。 |
| 屏幕变化 | 改变分辨率或移除外接屏幕后，组件与悬停按钮仍可操作。 |

## 6. 数据草案

```text
TodoItem
  id: 唯一标识
  text: 内容
  completed: 是否完成
  createdAt: 创建时间
  completedAt: 完成时间，可为空

WidgetSettings
  displayMode: expanded | icon | single
  positions: 各显示状态的位置
  isPinned: 是否固定且置顶
  lastActiveMode: 最小化前的显示状态
  singleItemId: 逐条显示时当前事项的 ID，可为空
```

数据默认保存在本机。具体存储格式和异常退出时的数据保护方案在技术设计中确定。
