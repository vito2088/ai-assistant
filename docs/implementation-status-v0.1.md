## 已实现

- 桌面待办：常驻输入框新增、完成切换、删除、展开列表、桌面小图标、悬停快捷按钮、紧凑列表。
- 文档导航：顶层“文档”包含“待办 / 速记”；旧顶层待办页面设置自动迁移。速记支持新增、编辑、删除并由 SQLite 独立保存。
- 工作台：顶层“工作台”包含电脑档案列表，每台电脑下有“项目 / 应用”。支持添加待绑定电脑档案、重命名和删除；当前电脑可管理和启动本机入口，其他电脑入口不可在本机启动。
- 窗口：拖动、固定并置顶、最小化到任务栏、托盘显示与退出、位置和状态恢复。
- 项目管理：手动选择项目文件夹和编辑器程序，保存、编辑、移除、一键打开。
- 软件管理：手动选择程序入口，保存、编辑、移除、一键启动。
- 设置：开机启动开关，读取系统注册状态并调用 Tauri 自启动插件启停。
- 工具：三个小图标入口，点击打开计算器、截图、录屏，返回按钮回到工具列表；Windows 原生整屏 PNG 截图与无声 H.264/MP4 录屏，提供保存路径、截图预览、录制计时和托盘停止入口。macOS/Linux 提供 WebView 屏幕选择与编码接口的能力检测及实现，目标系统尚未实测。
- 本地数据：SQLite 保存待办、速记、电脑档案、项目、应用入口及窗口设置。旧项目与软件入口自动归入当前电脑，软件类型迁移为应用。
