# 终端使用与实现范围

更新：2026-10-30。此文描述当前开发代码，不代表 GitHub 已发布的安装包包含这些功能。

## 使用

1. 在一级导航选择「终端」，点击二级侧栏的加号。
2. 选择「本地终端」或「SSH 连接」，填写名称和连接配置并保存。
3. 新建本地终端保存后会自动打开、选中新会话并聚焦输入；编辑已有连接只保存配置。SSH 配置保存后点击连接，再核对指纹与认证。连接菜单的「新建会话」可为同一配置再开一个会话。
4. 点击会话切换，关闭按钮会先确认。切换栏目、收起或最小化小助手不结束会话；退出应用会清理本地进程并断开 SSH。远端任务可能继续运行，断开不等于任务停止。

连接配置保存在本机 SQLite，应用重启后仍在。运行中的会话、终端输出和终端 AI 记录仅在当前进程中保留，不自动恢复命令或重放历史。删除连接不会强制关闭已打开的会话，这些会话显示在「未保存的会话」下。

连接下面始终显示已创建的子会话，只有一个会话也会展开显示；新建本地终端后自动选中第一个子会话，并显示连接状态。连接行的更多菜单提供新建会话、编辑与删除等操作；子会话的关闭按钮在悬停或键盘聚焦时显示。关闭到只剩一个会话时仍保留子项，全部关闭后保留连接配置。

终端二级侧栏默认宽 210px，小窗口下适当收窄。更多菜单使用独立悬浮层，不受列表滚动区域裁切，靠近窗口底部时向上展开；点击外部、按 Esc、滚动列表或切换页面会关闭菜单。

## 本地终端

使用 portable-pty 创建实际交互式终端，xterm.js 负责展示。Windows 支持 PowerShell、CMD 和已安装的 PowerShell 7（pwsh）；macOS / Linux 提供默认 Shell、bash、zsh、sh，所选 Shell 必须已安装。支持颜色、光标、交互输入、Ctrl+C、粘贴和尺寸调整。

每个会话保留自己的工作目录和进程。终端组件按需加载；输出有流量控制，历史行数有界。最多 24 个会话，包含尚未手动关闭的已结束会话。

## SSH 与凭据

- 首版提供密码、私钥文件及私钥口令认证，远程目录与命令按 Linux / POSIX Shell 处理。
- 首次连接先核对 SHA256 主机指纹；已有指纹变化时明确警告，未经用户重新信任不能发送登录凭据。
- 认证窗口不回显密码。留空可使用这条连接已保存的凭据；未设置口令的私钥也可直接留空。
- 可勾选保存到本机系统凭据库。保存的是密码或私钥口令，不在连接 JSON 中保存私钥内容。凭据库不可用时可以不勾选保存，手动输入后连接。
- 连接菜单可以清除保存的凭据；删除 SSH 配置或改变主机、端口、用户名、认证方式、私钥路径时会清除旧凭据。
- 不进行 SSH Agent 转发。跳板机、代理、SSH 配置导入、Agent、交互式 MFA 后续补充；当前需要 MFA 的账号会提示不支持，不绕过认证。

## 文件

SSH 会话右上角「远程文件」打开 SFTP 面板，复用已认证的连接：

- 路径输入、上一级、刷新、目录浏览、文件大小和符号链接标记。
- 文件选择器支持多文件上传；文件菜单支持下载、重命名与删除，工具栏支持新建文件夹。目录删除只允许空目录。
- UTF-8 文本预览最大 256 KB，二进制或更大文件请下载后查看；每次最多显示 2000 个目录项。
- 最多同时传输 4 个文件，显示进度、速度和结果，支持取消。
- 上传写入临时文件，完成后再改名。同名覆盖需要确认，替换前尝试保留备份，失败时尝试恢复；SFTP v3 并不保证所有服务器都能原子覆盖，断网或替换失败需核对服务器文件。
- 下载写入本地临时文件，完成后才放到选择的位置。取消不会把残缺文件当作完成文件。
- 暂不支持文件夹递归传输、断点续传、拖放上传或远程文本编辑。

## AI

右上角「AI 助手」默认使用设置中的主 AI，可选择已有 API 联系人，提供快速跳转模型设置和「解释选中内容」。只有主动提交的任务、选中的文字，以及经过授权、限量、过滤的工具结果会进入模型请求；不自动发送终端屏幕、输出历史或用户键盘输入。

当前工具：

| 工具 | 行为 |
| --- | --- |
| `terminal_execute` | 用户确认后执行一条非交互命令，显示结果、退出码与截断标记 |
| `terminal_list_files` | 用户确认后列出指定远程目录 |
| `terminal_read_file` | 用户确认后读取有限大小的远程文本；阻止常见凭据路径并检查规范路径 |

工具绑定当前会话，模型不能自行选择其他服务器或取得密码。API 联系人执行命令还需其自身权限允许命令；主 AI 也必须逐项确认。当前没有免确认自动执行模式。

AI 命令通过独立非交互通道运行，使用连接配置中的目录；不会继承人工终端后来执行的 `cd`、临时环境变量，也不会往用户正在输入的 Shell 中插入文字。需要密码、sudo、MFA 或全屏交互的操作由用户手动完成。单条命令最长 60 秒；本地进程用现有进程组清理机制，远程停止会发送终止请求并关闭通道，不能保证远端任务已经结束。结果不确定时不自动重试。

同一任务内重复的相同操作不会重复执行。终端 AI 每次发送是独立任务，界面保留当前运行期间的任务记录；需要继续操作时请明确提供目标或步骤。CLI 联系人暂不接入受管终端工具，但可由用户在本地交互终端中自行运行已安装的 CLI。

### 凭据边界

SSH 登录密码和私钥口令只经过认证界面、Rust 后端及 SSH 认证。AI 工具没有凭据读取接口；不把密码放入命令参数、环境变量、聊天、普通配置或同步记录。已知认证秘密、常见敏感配置值与私钥内容会在工具结果发送给模型前过滤。

过滤不等于系统沙箱。任意命令以目标账号权限执行，用户批准读取的日志或文件也可能包含未识别的秘密。尤其本地任意命令可能访问同账号下的文件或凭据库，不能同时开放完全访问并承诺所有秘密绝对不可获取。更强的隔离执行器、独立安全账号和文件/网络能力边界仍属于后续阶段。

## 设置与验证

开发时请使用 `npm run tauri dev` 启动完整桌面应用。`npm run dev` 只启动前端服务，不能更新已运行的 Rust 程序。如果界面已更新、旧桌面进程还在运行，可能出现 `Command terminal_load not found`；这不是默认会话。完全退出旧进程（包括托盘中的实例），再启动开发版即可。界面现在会显示版本不一致的重启提示，加载成功前禁用新增入口，避免继续调用缺失的接口。

「设置 → 终端设置」可以修改深浅主题、10–24px 字号、500–10000 行回滚历史；保存后应用到当前和新建会话。功能显示树可控制终端栏目及顺序，显示开关不代表执行授权。

开发检查：`npm test`、`npm run build`、`cargo test --lib`（在 `src-tauri` 下）。终端新增的测试覆盖单次提交、页面切换保留 DOM、未确认主机不进入认证、AI 上下文与审批绑定、实际本地 PTY、SSH 指纹、SFTP 文件往返、命令审批/取消/去重和秘密过滤。

Windows 原生界面自动化运行时本次无法初始化，未完成真实窗口视觉复核；macOS / Linux 运行表现仍需在对应系统验证。完整演进方案见 [终端模块设计](terminal-module-v0.1.md)。
