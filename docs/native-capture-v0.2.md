# 原生截图与录屏交互迁移 v0.2

日期：2026-10-29。本文记录当前实现；v0.1 原型和 capture-startup 文档保留为历史调研。

## 当前入口

Windows 截图和录屏默认进入原生窗口。界面按钮调用 Rust，系统全局快捷键由 Rust 的 global-shortcut 插件注册和处理，直接进入同一捕获服务，不依赖主 WebView 转发。默认 Ctrl+Alt+A 截图，Ctrl+Alt+R 开始/停止录屏；设置中可改键、停用，保留冲突提示和输入框编辑拦截。

不再提供“原生快速（试用）/完整标注”选项。已删除旧 capture.html、capture-overlay.ts/css、capture-border.html、旧预热池、会话展开与 WebView 录屏控制条接口。Windows 安装包不包含系统截图编辑页，也不会创建后台全屏捕获 WebView。

## 界面与图标

主界面保持现有 Web UI。原生捕获工具栏沿用 `capture-controls.css` 的浅色底、紫色选中态和主按钮，采用一致的圆角、固定图标尺寸与居中布局。图标由 `src/capture-icons.ts` 的同一份 SVG 轮廓生成 Direct2D 路径，包含圆弧转贝塞尔、圆角矩形、填充和线段，几何体在窗口创建时缓存，不使用字体字符替代。修改图标后运行 `python scripts/generate-native-icons.py`，前端测试检查源文件指纹，防止两套图标失配。

## 保留的能力

- 拖动框选、移动/调整选区、全屏、上次选区，支持显示器物理坐标。
- 画笔、箭头、矩形、椭圆、文字、马赛克、序号；颜色、粗细、撤销/重做。
- 文字使用 Win32 原生 EDIT 控件，支持中文输入；Ctrl+Enter 确认，也可点击工具栏提交。
- 对钩、Enter、Ctrl+C、双击选区复制并结束；复制同时写入 PNG 和 CF_DIB，保留尺寸与不透明像素。Esc、右键、× 取消。
- X 前保存按钮或 Ctrl+S 打开原生保存框，默认目录读取现有设置，取消保存留在编辑器。PNG 写入临时同目录文件后替换目标。
- 贴图复用独立桌面图片查看器，支持置顶、拖动、另存、关闭；微小选区仍预留图片下方独立操作条。
- 本地简中/英文 OCR 与 AI 文字翻译，沿用自动识别、自动译文设置；识别包含标注后的选区。结果在原生面板显示，可复制原文/译文、关闭。AI 翻译仅发送识别文字。
- 录屏原生框选、倒计时、返回选区、可拖动控制条、暂停/继续、停止与计时；现有 Windows Graphics Capture / H.264 编码链路保留。停止等待 MP4 封装结束，正常退出等待编码完成。

## 实现与性能边界

`desktop_snapshot.rs` 使用 GDI 获取 BGRA 内存快照，经 DwmFlush 等待需隐藏的小助手窗口完成合成。`native_capture.rs` 管理 Win32 消息循环、Direct2D 编辑器和录屏控制，`native_editor.rs` 负责标注模型和 WIC/Direct2D 图片导出，`native_capture_service.rs` 管理快捷键、互斥和生命周期。

初始框选不经过 PNG 文件、JavaScript 二进制传输或全屏 WebView。截图背景和 Direct2D 资源在隐藏状态准备，首次可见帧完整绘制；不在隐藏 HWND 上提交 EndDraw，避免隐藏窗口合成节流。原生捕获窗口及录屏边框请求 WDA_EXCLUDEFROMCAPTURE，减少窗口自身进入录屏的情况。

OCR 沿用本地 Tesseract.js/WASM，由 `native-capture-bridge.ts` 延迟加载并处理，UI、框选、标注、复制和快捷键不等待主 JavaScript。OCR 和 AI 翻译结果用会话 ID + 修订号回传；选区修改或关闭后丢弃过期结果，清理 OCR 临时图。主页面重新加载时可读取当前会话与未处理请求。

录屏开始后释放全屏快照和纹理，仅保留小控制条。此次没有迁移 OCR 引擎到 Rust，也没有实现滚动截图、自动吸附、音频录制或剪辑。Windows 合成器/显卡驱动的切换表现仍需实机体验，不能据此承诺所有电脑绝对无闪动。

## 平台范围

此次原生 UI 实现在 Windows。macOS/Linux 保留系统屏幕选择器及一次性的 `system-capture-editor` 图片编辑适配器，只有非 Windows 构建包含该页面；浏览器录屏仍依赖系统 WebView 的能力。独立贴图查看器仍使用轻量 WebView。其他系统的原生框选与录屏控制需要后续专门适配，当前未实机验证。

## 验证记录

自动检查覆盖热键解析、标注历史、裁剪方向/像素、各标注工具的实际 WIC 导出、PNG 通道与透明度、前端原生生命周期、录屏停止等待和过期 OCR/翻译丢弃。运行方式：`npm test`、`npm run build`、`cargo test --offline --manifest-path src-tauri/Cargo.toml --lib`。

桌面实测结果在本次迁移完成时追加；历史原型的性能数据不作为 v0.2 的测试结果。

## UI 统一收尾

截图、录屏和文字结果沿用浅色背景、淡紫边线、12px 卡片圆角、18px 矢量图标；操作按钮使用一致的居中和禁用/悬停反馈，不增加阴影。主界面捕获页采用紧凑设置卡片，开始操作有图标及文字，快捷键与倒计时/FPS/无声状态单独呈现。

录屏悬浮条压缩为 292×56 DIP：左侧为拖动区、状态点与计时，右侧为暂停/继续及停止。暂停态变为紫色，停止采用柔和红色，保存中禁用操作。左侧状态区可直接拖动，窗口应用实际圆角裁剪。鼠标离开后恢复状态文字，倒计时卡片在选区中间显示。

文字结果使用独立标题栏、内嵌白色阅读区和分区复制按钮，移除 Win32 编辑框自带的黑色边框。原文/译文同时显示时分成两个阅读区，错误不会覆盖已有的识别原文。macOS/Linux 系统选择器编辑页的结果卡片也使用同一配色和圆角。

本机桌面操作已验证：真实系统快捷键在主 JavaScript 暂停时仍可框选复制；PNG 与 CF_DIB 尺寸、颜色通道、透明度一致；标注和中文文字导出；原生保存对话框取消及实际写入；微小选区贴图；录屏倒计时返回、暂停/继续、快捷键停止并封装 MP4；旧 Windows 捕获 WebView 不再创建。本地 OCR 在合成英文/中文测试图上返回文字并清理中间草稿。新版 UI 复测：主界面录屏设置卡片无横向溢出，主操作高度 38px；暂停态、继续和停止操作正常。原生悬浮条实测尺寸为 292×56 DIP。双语结果面板使用固定处理结果验证两块无黑边阅读区及各自复制按钮；翻译服务返回在该 UI 测试中用固定文本模拟，不代表远端 AI 服务连通性测试。实际离线 OCR 已单独验证。成片使用浏览器解码后检查 800×600 画面像素，首帧及多个时间点有正常内容；校验需要等待视频帧完成呈现，不能仅在 loadeddata 回调立即取像素判断黑屏。前端 49 项与 Rust 36 项测试通过。

工具首页不再汇总待保存数据，截图页仅列出 PNG 截图，录屏页仅列出视频；预览、另存与删除入口跟随所属功能显示。

截图与录屏开始按钮旁提供设置齿轮，点击一次进入设置并定位到对应卡片。截图设置集中保存目录、自动 OCR 和自动译文；录屏设置集中保存目录、倒计时、帧率和鼠标指针选项。
