# AI 栏目配置引导

更新日期：2026-10-29

进入 AI 栏目时，若没有选中的有效模型配置，或当前云端模型没有已保存的 API 密钥，会在 AI 内容区域显示遮罩，中央显示“请先配置 API 密钥”和“前往配置密钥”。

遮罩下的会话、历史、引用、输入和发送等功能使用 inert 禁用，不能点击或通过键盘聚焦。顶部大栏目和窗口操作仍可使用。点击配置按钮跳转设置，并打开当前模型编辑弹窗；没有模型时打开新增模型弹窗。

保存并选中带有密钥的模型后，返回 AI 栏目即可正常使用；移除密钥后重新显示遮罩。已正确配置的 localhost / 127.0.0.1 / ::1 本地免密服务保持可用，避免要求本地服务填写无意义的密钥。密钥只通过既有凭据库逻辑保存，遮罩不读取或展示密钥正文。

测试覆盖无配置、云端缺密钥、保存后解除遮罩及本机免密配置；实际桌面检查覆盖遮罩点击阻挡与跳转模型编辑弹窗。
