# 功能显示设置

更新日期：2026-10-23

## 入口与结构

设置页中的“功能显示”使用两层复选框树，父级旁显示已选数量。

- 文档：待办、速记
- 工作台：项目、应用
- 工具：计算器、截图、录屏

设置不进入树结构，始终显示。默认全部勾选，旧用户升级后无需重新配置。

## 交互规则

- 点击父级整组勾选或取消；部分子项选中时父级显示半选，点击半选父级全选。
- 子项取消后隐藏对应子栏目或工具图标；某组全部取消后隐藏大栏目，剩余标签均分宽度。
- 全部取消仍保留设置，随时可重新启用。不可用的当前页面回退到首个可用栏目；组内回退到可用子栏目。
- 隐藏待办后同时隐藏桌面小图标的新增待办、紧凑列表入口。恢复旧紧凑模式时若待办已隐藏，则展开主界面。
- 隐藏截图或录屏时，对应待保存结果入口也隐藏，原文件保留。正在运行的录屏不因取消勾选而中断，仍可通过悬浮控制条或托盘结束；工具页可见时保留录制状态与停止操作。
- 每次变更自动保存成功后更新界面；失败提示并恢复原勾选。保存期间短暂禁用复选框以避免并发覆盖，更新后保留设置滚动位置和键盘焦点。

## 数据与后续扩展

SQLite `settings` 表中的 `feature_visibility` 保存叶子节点布尔值 JSON；父级状态从子项推导。此设置属于本机界面偏好，不修改业务数据。

新增功能在 `src/feature-visibility.ts` 注册；缺少的已知节点默认启用，未知字段忽略，格式损坏回退全部启用。未来数据同步时应单独决定是否同步此界面偏好。

## 验证范围

纯逻辑测试覆盖旧数据默认值、非法设置、父子联动、半选、全部隐藏后设置可达、序列化恢复和页面回退。桌面集成检查覆盖实际复选框点击、导航过滤、工具图标、重载恢复和桌面小图标入口。
