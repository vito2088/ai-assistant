# AI 聊天与内容助手 v0.1

日期：2026-10-24。

## 范围与入口

主导航第一项为 AI，设置中的功能显示可以隐藏该栏目及速记、截图里的 AI 操作。未配置模型时，待办、速记、工作台和捕获工具仍可独立使用。设置页各卡片统一保留 14px 间距。

- 聊天支持文字、手动引用速记、图片附件、流式输出、停止、失败重试、新建与删除会话。历史会话在页内展开，草稿及附件保存在本机。
- 速记支持整理、摘要、提取待办和继续聊。结果在原条目内展开，用户点击后才能另存、替换或添加待办。
- 截图详情支持解释、翻译及文字提取。继续聊沿用对应会话和图片快照。录屏分析不在本版范围。

## 模型与数据

Rust 使用 reqwest 调用配置服务的流式 Chat Completions 接口，不引入 LangChain、LangGraph、RAG 或向量数据库。服务地址可填写 API 根路径或完整的 /chat/completions 路径。云端仅接受 HTTPS，本机回环地址可使用 HTTP；不自动跟随重定向。

最多保存 50 个独立模型配置，同一服务可以添加多个模型或账号。每个配置包含名称、服务预设、可编辑地址与模型 ID、密钥、图片能力、默认翻译语言和连接测试。在设置的模型列表点击「使用」选择当前模型；聊天、速记和截图共用此选择，聊天页不显示模型切换控件。新增或测试第二个模型不会自动切换正在使用的模型；生成中禁止切换或修改配置。删除当前配置后选择剩余的第一个，删除最后一个后提示重新配置；聊天记录保持不变。

预设涵盖 DeepSeek、通义千问、Kimi、智谱、豆包、MiniMax、硅基流动、腾讯 TokenHub、百度千帆，以及 OpenAI、Claude、Gemini、Grok、Mistral、Groq、OpenRouter、Ollama 和 LM Studio。预设地址和模型建议依据 2026-10-24 的官方文档整理，来源在 `src/ai-presets.ts` 的 docs 字段。模型清单随服务变化，账号专属模型或接入点需手动填写。当前使用流式 Chat Completions 协议，Claude 使用其官方兼容接口，不包含各厂商专属工具和 Responses 功能。

图片能力由用户按模型实际能力配置，连接测试仅验证文本请求。密钥通过 keyring 保存在系统凭据库，不进入 SQLite 设置或前端返回值。新增配置的密钥按配置编号和服务地址隔离，更换地址或预设会清空尚未保存的密钥。无密钥的本机服务可留空。旧 `ai_config` 在读取时转换为 legacy 配置，保留原有凭据位置；第一次修改后保存至 `ai_config_v2`，空列表也不会重新导入旧配置。

只有当前会话以及用户明确引用的资料进入请求。发送前可移除附件。图片支持 PNG、JPEG、WebP，单张最多 8 MB，单次最多 4 份资料；后端限制消息数、响应大小及超时。

SQLite 的 ai_sessions 表保存会话 JSON，包括消息、附件内容快照、输入草稿、待办候选及替换撤销信息。引用原文或图片被修改、删除后，已有会话仍能继续。删除会话同时删除其中的附件；已经另存的速记和待办不受影响。

## 交互与一致性

- 生成任务独立于栏目；切换 Tab 后继续接收，返回时恢复聊天滚动位置。
- 会话保存按会话 ID 排队，各会话草稿分别延迟保存。删除会话前排空已排队保存，避免记录被旧保存重新创建。
- 初次保存尚未结束时停止生成，也会阻止随后发出网络请求。正在请求时取消会中断网络接收；部分输出保留，失败可重试。
- 应用重启后把未完成回答标记为中断，不自动再次发送。
- 速记替换和撤销使用原文比对；原文已变更或被删除时返回冲突提示。速记最多 2000 字。
- 待办候选可编辑、勾选；最多 50 项，每项最多 200 字。批量写入使用事务，失败全部回滚，已添加候选不能重复提交。
- 模型文字作为文本显示，不执行其中的 HTML 或脚本。模型不会直接执行文件、程序启动或数据修改。

## 验证与限制

已进行 TypeScript 检查、生产构建、前端回归测试以及 Windows Rust 编译和单元测试。自动化覆盖草稿保留、多会话保存、提前取消、重试、删除、待办确认，以及流式中文分块解析、速记冲突与撤销、待办事务回滚。

在 430 × 620 的浏览器窗口中，以模拟 Tauri IPC 和模型响应验证聊天、跨栏目生成、滚动恢复、候选编辑、速记替换撤销、截图详情翻译、继续聊、失败重试和停止。多模型回归覆盖新增和测试不改变活动模型、切换保留草稿、请求携带所选配置编号、删除保留历史、更换地址清空待保存密钥，以及后端迁移和凭据隔离。

尚未以真实模型服务验证响应效果或图片能力，也未实测 macOS/Linux 的系统凭据库和桌面交互。浏览器模拟验证不等于原生窗口与云端服务的端到端验证。
