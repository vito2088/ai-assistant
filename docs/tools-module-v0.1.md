# 工具模块 v0.1

- 日期：2026-10-23
- 顶层结构：文档 / 工作台 / 工具 / 设置
- 工具页使用三个小图标入口：计算器、截图、录屏；点击进入工具，使用“‹ 工具”返回，不使用子标签栏。

## 计算器

支持四则运算、括号、正负号、小数与百分比。百分比为后缀除以 100，`200*10%` 为 `20`。键盘 Enter 计算，Esc 清空；保留本次运行最近 8 次计算历史。解析器只接受算术语法，不使用 eval；除零、括号不匹配、溢出和无效字符在界面提示。

## 截图

Windows 枚举显示器，选择整块屏幕及 PNG 保存位置后执行原生捕获。可临时最小化助手，完成或失败后恢复。界面预览最近截图并显示文件位置，预览替换时释放旧图像资源。取消保存不执行截图。

其他桌面系统调用 WebView 的 getDisplayMedia 屏幕选择器；获取单帧后停止捕获，再保存 PNG。缺少接口或用户拒绝权限时给出提示。尚未在 macOS/Linux 实测，不承诺所有桌面环境都可用。

## 录屏

- Windows 使用 [windows-capture](https://docs.rs/windows-capture/latest/windows_capture/) 的原生捕获和编码，选择显示器与 MP4 保存路径后开始。H.264、无声、最多约 30 次画面更新/秒。较旧系统缺少帧间隔设置时回退到默认捕获并在回调中限制编码频率。
- 前端只接收录制状态，不传输 Windows 视频帧；未录制时不进行持续捕获。录制期间更新计时和状态，切换工具/大栏目不停止。
- 可自动最小化助手；停止入口在工具页、工具图标列表的录制状态条和系统托盘菜单。Windows 退出应用前完成编码收尾。
- macOS/Linux 在 WebView 支持时使用 [Screen Capture API](https://developer.mozilla.org/en-US/docs/Web/API/Screen_Capture_API) 与 MediaRecorder，按编码器能力选择 WebM/MP4。数据按块交给 Rust 写入临时文件，停止后提交保存，不在内存中积累整个视频。
- 本版不采集声音，不提供区域框选、暂停、剪辑或自动上传。录制期间需保持应用运行；强制结束进程可能使视频无法完成保存。

## 文件与权限

使用系统保存对话框明确选择保存位置；Rust 检查绝对路径、存在的父目录和扩展名。浏览器捕获的写入任务使用独立 ID，限制每个分块大小，完成后清理临时文件。Windows 文件输出来自原生编码器，不依赖外部 FFmpeg。

## 验收

1. 四个顶层栏目可切换，工具页展示三个图标。
2. 运算优先级、括号、小数、正负号、百分比正确；无效表达式和除零报错。
3. Windows PNG 文件可读取，像素尺寸与所选屏幕一致。
4. MP4 可解码、有正确尺寸和时长；停止后恢复空闲状态。
5. 截图取消或失败不遗留捕获；录屏状态在切换栏目和最小化后保持，可停止并保存。
6. 保存取消、权限拒绝、接口缺失与写入失败提供可理解的反馈。
