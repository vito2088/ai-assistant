# 定时器与提醒

更新日期：2026-10-29

工具页统一为一个“提醒”图标，列表同时展示倒计时和指定时间任务。“新增提醒”打开创建弹窗，在弹窗中选择倒计时或指定日期时间、填写内容及屏幕提醒开关；取消和 Esc 关闭创建弹窗。设置的功能显示树只保留“提醒”，隐藏入口不会取消已有任务。旧的定时器与提醒显示开关合并迁移。

- 定时器：输入小时、分钟、秒，添加提醒内容，支持开始、暂停、继续、取消。
- 提醒：选择本地日期时间，添加一次性提醒；支持取消、到点确认和延后五分钟。
- 列表每条任务提供“编辑”，打开回填数据的弹窗，可修改内容、提醒方式、时间和屏幕提醒开关。保存更新原任务，不新增副本；取消或 Esc 不写入修改。只改内容/开关时保留原截止时间和状态；修改倒计时长度从保存时重新计时，暂停中的倒计时仍保持暂停；修改日期或切换方式会按新时间重新安排。
- 每项任务独立设置“屏幕弹窗提醒”，默认开启。关闭时仍正常计时，到点只在任务列表标记“已到时间”。
- 屏幕提醒使用独立、置顶的小横条窗口，内容高度约 60px，缩小图标与上下留白，提醒内容单行显示，长内容可悬停查看完整文本。横向居中，横条顶部停在距主显示器顶部约 100 个逻辑像素的位置；从屏幕顶部外侧滑入，不覆盖整个桌面，横条之外的桌面可继续操作。支持“知道了”、Esc、五分钟后再提醒；多个到期任务依次显示。系统设置减少动态效果时关闭动画。

SQLite `timed_tasks` 表持久化任务内容、绝对到期时间、状态及屏幕提醒开关。Rust 后台每秒检查到期时间，计时不依赖前端页面、WebView 的 setInterval 或主窗口显示状态；列表倒计时仅用于显示。

暂停时保存剩余时长，继续时从当前时间重新计算截止时间。到期状态只转换一次，屏幕提醒在用户确认前保留；休眠恢复、重启应用后补处理过期任务。应用完全退出或电脑关机期间不能弹窗，重新启动小助手后补显示；可配合开机启动使用。

提醒为本地功能，不调用 AI、不请求网络。当前为一次性提醒，不包含每日/每周重复、声音和系统通知。

验证覆盖暂停/继续、精确到点、重复检查不重复触发、延后五分钟、确认后不再触发，以及多个过期任务补处理。
