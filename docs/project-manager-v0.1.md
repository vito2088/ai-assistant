- 所属产品：[桌面小助手产品总览 v0.3](product-overview-v0.3.md)

## 1. 目标

用户为一个本地项目保存名称、项目文件夹地址和要使用的编辑器。以后打开小助手的“项目”页，点击该项目的“打开”，即可用保存时选择的编辑器打开对应文件夹。

本稿将“剪辑器”暂按前文的“编辑器”理解，即代码编辑器或其他可打开项目文件夹的应用。如果实际想管理视频剪辑项目，后续需单独调整项目类型、文件选择和打开方式。

## 2. 核心流程

```text
进入“项目”页
  → 点击“＋ 新建项目”
  → 输入项目名称
  → 选择编辑器
  → 选择项目文件夹
  → 保存
  → 项目出现在列表中
  → 点击“打开”
  → 使用该项目保存的编辑器打开其文件夹
```

每个项目各自记住编辑器；更换全局默认编辑器不会改变已有项目。

## 4. 详细交互

### 4.1 新建项目

- 点击“＋ 新建项目”打开表单。
- “名称”可由所选文件夹名自动填入，用户可以修改。
- “编辑器”列出可用选项；用户选择一个用于打开该项目的应用。若无法自动识别目标编辑器，允许手动指定应用程序位置。
- “地址”通过系统文件夹选择器选择，另可粘贴路径。首版按项目**文件夹**处理。
- 名称、编辑器和地址均为必填。保存前检查文件夹存在、编辑器可用。
- 同一个项目文件夹允许保存一次；再次选择时提示打开或编辑已有记录，避免重复。
- 保存成功后返回列表，新项目可立即点击“打开”。

### 4.2 一键打开

- 点击项目行的“打开”，直接使用该项目保存的编辑器打开保存的文件夹，不再要求重复选择。
- 打开请求发出后给出简短反馈；如果编辑器启动失败，显示失败原因和“编辑项目”入口。
- 如果项目文件夹已移动或删除，显示“项目地址不可用”，引导重新选择地址。
- 如果编辑器已卸载或位置变化，显示“编辑器不可用”，引导重新选择编辑器。
- 点击项目行可进入详情或选中项目，但不会误触发外部应用；只有明确点击“打开”才启动编辑器。

### 4.3 管理项目

- 项目行的“⋯”菜单提供“编辑”和“从列表移除”。
- 编辑时可以更改名称、编辑器和项目地址；保存后下一次打开使用新设置。
- “从列表移除”只删除小助手里的快捷记录，不删除磁盘上的项目文件夹；移除前明确提示。
- 首版按最近打开时间排序；尚未打开过的项目排在列表末尾。提供按名称搜索，便于项目增多后查找。
- 列表为空时显示“还没有项目，点击＋添加”。

## 5. 数据草案

```text
ProjectEntry
  id: 唯一标识
  name: 显示名称
  folderPath: 项目文件夹绝对路径
  editorId: 已选编辑器的标识
  editorExecutablePath: 自定义编辑器的程序位置，可为空
  createdAt: 创建时间
  lastOpenedAt: 最近点击打开的时间，可为空
```

路径只作为本机快捷入口保存。小助手不复制、不修改项目文件夹内容。具体编辑器启动参数在技术设计中按各编辑器适配，不把路径拼接成未经处理的命令字符串。

## 6. 首版验收标准

| 功能 | 验收标准 |
| --- | --- |
| 新建 | 能填写名称、选择编辑器与文件夹，并保存为项目记录。 |
| 校验 | 必填项缺失、文件夹不存在、编辑器不可用时不能静默保存。 |
| 打开 | 点击“打开”后，选定编辑器打开正确的项目文件夹。 |
| 编辑 | 修改任一保存项后，再次打开使用新配置。 |
| 移除 | 从列表移除后，磁盘上的项目文件不受影响。 |
| 持久化 | 重新启动小助手后，项目记录与所选编辑器仍在。 |
| 异常 | 路径失效或编辑器不可用时，能看到可理解的提示并修复。 |

## 7. 首版边界与后续候选

首版聚焦本地项目快捷打开，不做 Git 仓库状态、项目任务看板、云同步和团队协作。后续可增加项目分组、收藏、最近使用、多个打开动作和与待办关联。
