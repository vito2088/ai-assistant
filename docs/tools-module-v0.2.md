更新日期：2026-10-29。沿用工具小图标入口，不增加子 Tab。

快捷键启动与取屏链路进一步优化，见 [捕获启动优化 v0.3](capture-startup-v0.3.md) 和 [窗口常驻复用 v0.4](capture-startup-v0.4.md)：Windows 静态底图使用一次性 GDI 快照；预热并复用透明选区窗口，启用原生透明窗口防白闪选项，按会话清理画面和交互状态。

后续原生化、跨平台后端与现成组件的选择，见 [截图与录屏性能、架构调研](capture-architecture-research-2026-10-29.md)。该文为建议，尚未替换现有实现。

Windows 已提供独立的 [原生快速截图原型](native-capture-prototype-v0.1.md)，在截图页选择「原生快速（试用）」即可体验，本次运行的截图按钮和快捷键随模式切换。

## 样式统一（2026-10-23）

- 截图、录屏、贴图工具栏使用与小助手一致的暖白背景、淡紫强调色、细边框与圆角，不添加外沿阴影。
- 操作按钮使用统一 24×24 viewBox 的线性 SVG，常规按钮 34px、图标 18px；保留 title、aria-label、选中/禁用和焦点状态。
- 设置的目录输入框、文件夹选择与重置图标按钮均为 38px 高，长路径省略显示并提供完整路径提示；无默认路径时重置按钮禁用。
- 设置内容可滚动，底部选项与页脚不重叠。截图和录屏面板中的开始、暂停、结束与草稿操作也使用同一套图标按钮。
- 实测两组目录控件高度均为 38px，无横向溢出；截图工具栏 16 个按钮均有图标及说明，画笔选中状态正确；录屏暂停、继续、结束可用。

这一版优先把获取画面、修改、取消、完成、保存和恢复连成完整流程。录制视频在 Rust 中捕获、裁剪、编码、写盘，前端不接收逐帧视频。区域裁剪使用原生帧缓冲，重用去除行填充的缓冲区；60 FPS 是目标上限，不承诺所有电脑或 4K 画面能持续达到。

## 截图流程

1. 选择显示器、是否隐藏小助手。
2. 先捕获干净的桌面画面，再打开独立置顶编辑窗口；避免把编辑工具栏截进图里。
3. 框选、移动、八方向调整；支持全屏与相同分辨率的上次选区。
4. 画笔、箭头、矩形、椭圆、文字、马赛克、序号；可选颜色、线宽；撤销/重做。
5. 对钩、Enter 或 Ctrl+C 默认复制选区及标注并结束截图（依赖系统 WebView 剪贴板支持）；独立复制按钮移除。复制成功后清理临时源画面，不自动弹出保存框，也不生成待保存副本；复制失败保留编辑界面供重试或另存。
6. X 前提供保存图标，Ctrl+S 也可另存本地 PNG；取消保存继续编辑。固定到桌面的截图仍保留结果草稿供以后另存。

### 固定截图到桌面

截图工具栏新增“固定”。未框选时禁用；点击后导出选区及标注，创建独立置顶贴图并结束截图模式，不弹出保存对话框、不抢回主窗口焦点。贴图位于原选区位置，支持多张并存。小选区保持最小可操作尺寸，窗口额外预留 44px 高的透明区域容纳独立操作条。

- 拖动图片移动窗口，悬停在图片下方显示置顶开关、另存和关闭，按钮不覆盖图片；小图也能完整显示三个按钮。操作条支持键盘聚焦，Esc 关闭。
- 另存使用设置中的截图默认目录。贴图加载后在内存中保留图片，即使主面板已经另存或删除对应草稿，当前贴图仍能显示和另存。
- 关闭贴图不会删除原草稿；退出应用关闭所有贴图，下一次不自动打开。
- 使用独立窗口权限，关闭贴图时销毁窗口，避免遗留不可见的置顶窗口。
- Windows 实测：600×375 标注截图成功固定，截图编辑窗口退出；原生置顶状态切换正确，关闭后贴图窗口销毁，草稿仍保留。前端构建与 Rust 检查通过。

快捷键：V 选区、P 画笔、A 箭头、R 矩形、O 椭圆、T 文字、M 马赛克、N 序号；Ctrl+Z/Ctrl+Shift+Z 撤销/重做；Enter 复制并结束；Ctrl+S 另存；Esc 取消。文字编辑中 Ctrl+Enter 提交，Esc 结束文字输入而不是退出整个捕获。

当前标注是顺序绘制模型，已提交对象通过撤销移除；尚不提供独立对象移动和二次文字编辑。马赛克用于遮挡显示，不等同于不可逆安全擦除。

## 录屏流程

1. 使用相同的桌面框选，支持全屏与上次选区。
2. 0/3/5/10 秒倒计时；倒计时中 Esc 返回选区。
3. 显示可拖动控制条、计时、暂停/继续、结束；选区蓝色边框穿透鼠标。
4. Windows 控制条与边框设置为捕获排除窗口。主面板、控制条、托盘都能结束录制。
5. 暂停时不送入视频帧，恢复后从视频时间戳中扣除暂停时长。
6. 结束后完成编码并恢复主窗口，展示视频预览与另存操作；取消保存或重新打开软件可继续处理草稿。

格式为无声 H.264 MP4；15/30/60 FPS；是否包含鼠标可配置。编码要求选区宽高为偶数，因此最多裁掉右侧/底部一个像素。退出应用时先结束编码；强杀进程、断电后的未完成视频不保证可恢复。

## 设置与数据

- 截图、录屏分别设置默认保存目录；作为保存对话框初始目录，保存发生在捕获完成后。
- 设置存 SQLite 的 `capture_preferences`。目录属于本机设置，不应跨设备同步。
- 本机草稿：应用本地数据目录 `capture-drafts/capture-<UUID>.<ext>`；不自动上传。
- 预览协议仅允许读取草稿目录。删除命令检查草稿目录和文件名，不删除任意用户路径。
- 文件复制在 Rust 工作线程执行；写入目标同目录临时文件后重命名。失败保留源草稿，成功后再清理。
- 待保存列表展示时间和大小，支持预览、另存、确认删除。不自动删除用户未保存的结果。

## 平台范围

Windows 为原生捕获路径。本轮的桌面框选、区域录制、独立控制条和穿透边框针对 Windows 实现。macOS/Linux 保留 WebView 系统选择器、截图标注与浏览器录制降级流程；区域录屏和控制条尚未移植，且尚无实机验证。后续需要分别落地 ScreenCaptureKit / PipeWire 等系统接口，不能只以 Web UI 编译成功宣称跨平台完成。

## 捕获切换优化（2026-10-29）

- 原生捕获前，先记录主窗口显示、最小化与焦点状态；确需排除小助手时直接暂时隐藏，取代最小化动画和固定 300ms 等待。已经隐藏/最小化的窗口保持原状态，截图复制或取消时按此前状态恢复，避免快捷键调用时弹出主界面。
- 选区窗口初始隐藏，PNG 解码和首次 canvas 绘制完成后才显示、聚焦，避免加载阶段露出深色整屏。隐藏 WebView 的动画帧可能被暂停，因此准备等待包含有界超时；初始化失败仍显示错误及取消出口。
- 贴图也在图片解码后显示，避免空白初始帧。操作条放在独立预留区域，深浅色背景与图片区域分开。
- 录屏倒计时结束时，先把原选区窗口缩小，再绘制浅色控制条，避免全屏浅色背景闪现；控制条绘制后再启动编码。
- Windows 实际检查覆盖：快捷键回调同一路径打开截图、对钩复制后关闭且无保存弹框/副本、微小选区固定后按钮不与图片重叠、已最小化主窗口在取消后保持最小化，以及区域录屏开始/结束。改善的是应用自身的窗口切换；不同系统的屏幕捕获提示和权限界面由系统控制。
