# 工具增强 v0.2

日期：2026-10-23。沿用工具小图标入口，不增加子 Tab。

## 参考与取舍

- [ShareX 区域捕获](https://getsharex.com/docs/region-capture)：框选后调整、标注、快捷键和完成后的操作。
- [Snipaste](https://www.snipaste.com/)：桌面内标注、画笔/形状/文字/马赛克、撤销重做、多屏与高 DPI。
- [Screen Studio](https://screen.studio/)：区域录制与录制后的结果处理。

这一版优先把获取画面、修改、取消、完成、保存和恢复连成完整流程。录制视频在 Rust 中捕获、裁剪、编码、写盘，前端不接收逐帧视频。区域裁剪使用原生帧缓冲，重用去除行填充的缓冲区；60 FPS 是目标上限，不承诺所有电脑或 4K 画面能持续达到。

## 截图流程

1. 选择显示器、是否隐藏小助手。
2. 先捕获干净的桌面画面，再打开独立置顶编辑窗口；避免把编辑工具栏截进图里。
3. 框选、移动、八方向调整；支持全屏与相同分辨率的上次选区。
4. 画笔、箭头、矩形、椭圆、文字、马赛克、序号；可选颜色、线宽；撤销/重做。
5. Ctrl+C 复制当前选区与标注（依赖系统 WebView 剪贴板支持）；复制后可继续编辑。
6. 完成后生成 PNG 草稿、退出桌面编辑、恢复小助手，再选择保存位置。取消保存保留草稿。

### 固定截图到桌面

截图工具栏新增“固定”。未框选时禁用；点击后导出选区及标注，创建独立置顶贴图并结束截图模式，不弹出保存对话框、不抢回主窗口焦点。贴图位于原选区位置，支持多张并存。小选区的窗口会适当放大，以容纳操作按钮。

- 拖动图片移动窗口，悬停显示置顶开关、另存和关闭；Esc 关闭。
- 另存使用设置中的截图默认目录。贴图加载后在内存中保留图片，即使主面板已经另存或删除对应草稿，当前贴图仍能显示和另存。
- 关闭贴图不会删除原草稿；退出应用关闭所有贴图，下一次不自动打开。
- 使用独立窗口权限，关闭贴图时销毁窗口，避免遗留不可见的置顶窗口。
- Windows 实测：600×375 标注截图成功固定，截图编辑窗口退出；原生置顶状态切换正确，关闭后贴图窗口销毁，草稿仍保留。前端构建与 Rust 检查通过。

快捷键：V 选区、P 画笔、A 箭头、R 矩形、O 椭圆、T 文字、M 马赛克、N 序号；Ctrl+Z/Ctrl+Shift+Z 撤销/重做；Enter 完成；Esc 取消。文字编辑中 Ctrl+Enter 提交，Esc 结束文字输入而不是退出整个捕获。

当前标注是顺序绘制模型，已提交对象通过撤销移除；尚不提供独立对象移动和二次文字编辑。马赛克用于遮挡显示，不等同于不可逆安全擦除。

## 录屏流程

1. 使用相同的桌面框选，支持全屏与上次选区。
2. 0/3/5/10 秒倒计时；倒计时中 Esc 返回选区。
3. 显示可拖动控制条、计时、暂停/继续、结束；选区蓝色边框穿透鼠标。
4. Windows 控制条与边框设置为捕获排除窗口。主面板、控制条、托盘都能结束录制。
5. 暂停时不送入视频帧，恢复后从视频时间戳中扣除暂停时长。
6. 结束后完成编码并恢复主窗口，展示视频预览与另存操作；取消保存或重新打开软件可继续处理草稿。

格式为无声 H.264 MP4；15/30/60 FPS；是否包含鼠标可配置。编码要求选区宽高为偶数，因此最多裁掉右侧/底部一个像素。退出应用时先结束编码；强杀进程、断电后的未完成视频不保证可恢复。

## 设置与数据

- 截图、录屏分别设置默认保存目录；作为保存对话框初始目录，保存发生在捕获完成后。
- 设置存 SQLite 的 `capture_preferences`。目录属于本机设置，不应跨设备同步。
- 本机草稿：应用本地数据目录 `capture-drafts/capture-<UUID>.<ext>`；不自动上传。
- 预览协议仅允许读取草稿目录。删除命令检查草稿目录和文件名，不删除任意用户路径。
- 文件复制在 Rust 工作线程执行；写入目标同目录临时文件后重命名。失败保留源草稿，成功后再清理。
- 待保存列表展示时间和大小，支持预览、另存、确认删除。不自动删除用户未保存的结果。

## 平台范围

Windows 为原生捕获路径。本轮的桌面框选、区域录制、独立控制条和穿透边框针对 Windows 实现。macOS/Linux 保留 WebView 系统选择器、截图标注与浏览器录制降级流程；区域录屏和控制条尚未移植，且尚无实机验证。后续需要分别落地 ScreenCaptureKit / PipeWire 等系统接口，不能只以 Web UI 编译成功宣称跨平台完成。

## 本轮验收记录

- Windows 本机 3840×2160、150% 缩放：桌面选区 500×300 逻辑像素生成 750×450 PNG 与 MP4，选区坐标正确。
- 实际操作矩形、箭头、文字、画笔、马赛克、撤销/重做；文字输入保持焦点，完成后文件可打开。
- 暂停约 2 秒并继续录制，输出视频约 4.47 秒；暂停时间不计入编码时间线。控制条大小 340×64，开始、暂停、继续、结束状态一致。
- 实际读取 MP4 元数据与预览画面：750×450，画面方向正确。修复原始 BGRA 行顺序造成的上下颠倒，并加入单元测试。
- 倒计时 Esc 返回选区，再次 Esc 取消；草稿数量恢复，录制未启动。
- 截图完成后实际另存成功；取消保存保留草稿；失败目标目录不破坏源草稿；拒绝通过草稿删除接口删除目录外的文件。
- 设置修改后能从 SQLite 读回，重启后草稿仍可列出。
- `npm run build`、`npm test`、`cargo test --lib` 通过。Rust 测试覆盖选区越界/偶数尺寸、视频行方向和现有数据迁移。
- 尚未实测：多显示器混合缩放、长时间 4K/60 FPS、macOS/Linux、系统剪贴板在不同 WebView 版本上的兼容性。
