# 软件管理｜功能设计 v0.1

- 状态：讨论稿，尚未开发
- 日期：2026-10-23
- 所属产品：[桌面小助手产品总览 v0.4](product-overview-v0.4.md)

## 1. 目标

用户把常用软件添加到小助手中，之后在“软件”页点击一次“打开”，即可启动该软件。这个功能管理的是**启动入口**，不负责安装、卸载或更新软件。

与项目管理的区别：软件管理只打开软件本身；项目管理使用指定编辑器打开指定项目文件夹。

## 2. 核心流程

```text
进入“软件”页
  → 点击“＋ 添加软件”
  → 从已安装软件中选择，或手动选择程序文件
  → 确认名称、图标和启动入口
  → 保存
  → 软件出现在列表
  → 点击“打开”启动软件
```

首版按 Windows 本机软件设计。是否能列出某类已安装应用，取决于技术方案；手动选择程序文件作为可靠的基础添加方式。

## 4. 详细交互

### 4.1 添加软件

- 点击“＋ 添加软件”打开表单。
- 可以从可识别的已安装软件列表选择；也可以浏览并选择本地可执行程序。首版不要求用户手填启动命令。
- 选择软件后自动填入名称与图标，用户可修改名称和图标。
- 保存前检查启动入口有效。缺少名称或启动入口时给出明确提示。
- 已添加过相同启动入口时，提示打开或编辑已有记录，避免重复。
- 保存后返回列表，新软件可以立即点击“打开”。

### 4.2 一键打开

- 每条软件记录有清晰的“打开”按钮；点击后使用保存的启动入口启动软件，不再弹出选择器。
- 启动成功时给出短暂反馈。若软件已卸载、程序文件移动或启动失败，显示“软件无法打开”及原因，并提供“编辑入口”。
- 点击列表行只选中或查看软件，不直接启动；明确点击“打开”才运行外部程序，避免误触。
- 对可能需要系统授权的程序，遵循操作系统自身的提示与确认。

### 4.3 管理列表

- 每条记录的“⋯”菜单提供“编辑”和“从列表移除”。
- 编辑可修改显示名称、图标和启动入口。
- 从列表移除只删除小助手中的快捷入口，不卸载软件，也不删除程序文件；移除前明确提示。
- 首版支持按名称搜索；默认按最近打开时间排序，尚未打开过的软件放在后面。
- 列表为空时显示“还没有常用软件，点击＋添加”。

## 5. 数据草案

```text
SoftwareEntry
  id: 唯一标识
  name: 显示名称
  launchTarget: 可启动的软件入口
  iconRef: 图标来源或本地图标引用，可为空
  createdAt: 创建时间
  lastOpenedAt: 最近点击打开的时间，可为空
```

保存启动入口时应保留入口类型（例如已安装应用标识或程序文件路径），由技术方案决定具体字段。启动时将用户选择的路径作为参数传递给系统接口，不拼接未经处理的命令字符串。

## 6. 首版验收标准

| 功能 | 验收标准 |
| --- | --- |
| 添加 | 可选择本机软件或程序文件，确认名称后保存。 |
| 打开 | 点击“打开”后启动对应软件，不需要再次查找程序。 |
| 编辑 | 修改名称、图标或启动入口后，列表展示和打开行为同步更新。 |
| 移除 | 从列表移除后，已安装软件及其文件不受影响。 |
| 持久化 | 重启小助手后，软件入口和自定义名称仍在。 |
| 异常 | 软件入口失效时，能看到原因和修复入口。 |

## 7. 首版边界与后续候选

首版不做软件安装、卸载、版本更新、进程管理和自动启动。后续可增加收藏置顶、分类、快捷键，以及把少量常用软件放进桌面小图标的快捷菜单。
