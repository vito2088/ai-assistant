# 模型连接测试与智谱接入

更新日期：2026-10-30。

模型配置弹窗顶部提供「测试连通」，底部是「取消 / 保存配置」。测试和保存分开：只有点击「保存配置」才写入模型设置与密钥。

## 主 AI

「设置 → AI 模型」顶部提供「主 AI」选择器，选择一个已保存的模型配置后立即绑定并自动保存，重启后继续使用。模型列表也可通过「设为主 AI」切换，当前主 AI 带有标记。选项显示配置名称及其当前实际模型，便于区分同一服务下的多个模型配置。

AI 翻译、速记整理/摘要/提取待办、截图解释等单 AI 功能共用这个选择。截图文字翻译可用纯文本模型，截图图片解释仍需主 AI 开启并实际支持图片能力。已经开始的请求继续使用发起时的模型，后续请求采用新的主 AI。

通讯录联系人仍按自己的服务和模型绑定执行，切换主 AI 不会批量修改群组或私聊联系人。首次保存模型时会自动成为主 AI；删除当前主 AI 后沿用现有规则选择剩余配置，没有配置时显示添加提示。切换保存失败会保留原绑定。

## 测试与取消

- 测试当前草稿中的地址、选中模型和输入密钥，不要求先保存配置名称或所有映射行，不会切换全局模型。
- 没有重新输入密钥时，仅可读取同一配置、同一地址已保存在系统凭据库中的密钥；更换地址或新增配置需填写密钥。本机免密服务可留空。
- 只发送一条固定测试消息，不发送聊天记录、速记、文件、图片，也不保存测试回复到聊天。
- 测试中顶部显示「测试中…」，可以点击底部「取消」或右上角关闭来中止。若还有未保存编辑，会沿用应用内的放弃修改确认。
- 成功显示耗时；失败区分认证、地址/协议、模型权限、余额、套餐额度、超时和网络问题，并显示 HTTP 状态及可识别的服务错误码。不会展示未经筛选的服务响应或密钥。
- 修改连接字段后清除旧的测试反馈。连接测试只验证一次文本请求；图片、工具调用和流式聊天仍需实际使用验证。

测试最长 45 秒。智谱当前 GLM 推理模型在测试时关闭思考并设置小输出预算，减少单纯检查连接的耗时与用量；聊天请求仍采用正常聊天配置。

模型映射的下拉箭头仅在成功获取模型列表后显示；未获取、获取失败，或更换服务地址/密钥后会隐藏，输入框恢复完整圆角，仍可手动填写模型 ID。

## 智谱与 CC Switch 的区别

智谱的标准 API、Coding Plan 和 Anthropic 兼容接口使用不同地址。CC Switch 配置 Claude Code 时可能使用 Anthropic 通道，不能把该地址直接当作本应用的 Chat Completions 地址使用。[智谱官方接入说明](https://docs.bigmodel.cn/cn/coding-plan/tool/others)、[标准 OpenAI 兼容接口](https://docs.bigmodel.cn/cn/guide/develop/openai/introduction)。

| 使用方式 | 预设 / 协议 | Base URL |
| --- | --- | --- |
| 开放平台标准 API | 智谱 GLM · 标准 API | `https://open.bigmodel.cn/api/paas/v4` |
| Coding Plan 的 Chat 接口 | 智谱 GLM · Coding Plan | `https://open.bigmodel.cn/api/coding/paas/v4` |
| CC Switch 中的 Claude Code | Anthropic Messages | `https://open.bigmodel.cn/api/anthropic` |
| Coding Plan 的 Responses 接口 | Responses，不用于本应用的模型服务 | `https://open.bigmodel.cn/api/v1` |

有 Coding Plan 额度不代表标准 API 余额充足。密钥正确也可能因为地址、模型权限或套餐不匹配而失败。请先选择对应预设，再填写该通道的密钥和账号可用模型。本应用不会在失败后自动切换计费通道，也不会修改 CC Switch 配置。套餐适用工具、模型与账号权限以智谱平台规则为准。

如果直接添加本机 Claude Code 联系人，仍然沿用 Claude Code 自身以及 CC Switch 已经配置的模型和认证，无需把 Anthropic 地址转换成自定义 API 服务。

## 实现与验证

- `src-tauri/src/ai_connection.rs`：独立草稿测试命令、同地址凭据读取、超时/取消、结构化错误和响应检查。
- `src/ai-connection.ts`：错误分类的中英西文展示。
- `src/ai-presets.ts`：标准 API 与 Coding Plan 分别提供预设，已有标准 API 配置不会自动改地址。
- `src/ai.ts`：顶部测试、底部取消/保存、进行中取消与结果反馈。

验证覆盖真实本地 HTTP 请求、Bearer 认证、当前草稿模型、错误码分类与脱敏、测试不保存/不切换、取消测试、配置保存失败保留编辑。另使用现有智谱配置的密钥进行最小文本请求验证：Coding Plan Chat 接口返回 HTTP 200 和文本；未复制或修改 CC Switch 配置，也未为此测试保存模型配置。
